# docs/

`wallet-options.png` — screenshot of the "Connect Wallet" modal showing the
available wallet options (Freighter + others via StellarWalletsKit).

This repo does not include a generated screenshot. To add it:

1. Run the frontend locally (`npm run dev` inside `frontend/`).
2. Click "Connect Wallet".
3. Take a screenshot of the modal that lists Freighter, xBull, Albedo, etc.
4. Save it as `docs/wallet-options.png` and commit it.
